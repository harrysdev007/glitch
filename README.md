# BNB故障 OS

Chinese desktop-style website for BNB故障 ($故障 / $GLITCH).

## Run locally

Run any static HTTP server in this folder, for example:

    npx serve .

Open the printed local address. No build step is required.

## Features

- Interactive compressed 3D character directly on the desktop
- Draggable windows, terminal, gallery, and persistent preferences
- Official X: https://x.com/bnbglitch_fun
- Responsive Chinese interface, black / white / yellow palette

The GLB was optimized from 18.9 MB to 1.08 MB. Draco decoders and the model viewer are included locally.

## Hosting

Deploy this directory as a static website. Entry point: index.html. Build command: none.
